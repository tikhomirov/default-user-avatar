# Default User Avatar

[![Version](https://img.shields.io/badge/version-1.0.8-blue.svg)](https://github.com/tikhomirov/default-user-avatar/releases)
[![WordPress](https://img.shields.io/badge/WordPress-4.6%2B-blue.svg)](https://wordpress.org/)
[![PHP](https://img.shields.io/badge/PHP-7.2%2B-purple.svg)](https://php.net/)

Sets a custom default avatar for WordPress users when no Gravatar is configured.

## Requirements

| Component | Minimum |
|-----------|---------|
| **WordPress** | 4.6 |
| **PHP** | 7.2 |

## Features

- Custom default avatar URL
- Configurable image path in plugin constructor
- Composer package `rwsite/default-user-avatar`

## Installation

### Composer

```bash
composer require rwsite/default-user-avatar
```

### Manual

1. Download the [latest release](https://github.com/tikhomirov/default-user-avatar/releases).
2. Upload to `wp-content/plugins/default-user-avatar/`.
3. Activate **Default User Avatar**.
